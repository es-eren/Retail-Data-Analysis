# 📊 Retail Sales Analysis Project

## 📌 Project Overview

This project analyses sales data to identify trends, customer behaviour, and opportunities to increase revenue. The goal is to generate actionable insights that can support business decision-making.

---

## 🎯 Objectives

* Analyse revenue trends over time
* Identify high-value customer segments
* Explore purchasing behaviour
* Provide data-driven recommendations

---

## 📂 Dataset

The dataset contains transaction-level data from 2017 to 2020, including:

* Customer demographics
* Purchase history
* Product categories

---

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy, Statsmodels)
* Data visualisation (Matplotlib, Seaborn)
* Jupyter Notebook
* SQL

---

## 📈 Key Insights

* Customers aged 45–54 contribute the highest revenue
* Customers with children have higher basket value
* Certain product categories drive repeat purchases

---

## 🚀 How to Run the Project

1. Clone the repository
2. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open the notebook:

   ```bash
   jupyter notebook
   ```
4. Run the analysis notebook
